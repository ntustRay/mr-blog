![JavaScript：React-Slick bug: 點選dot往左或往右滑，會出現多個dots在手機上，圖 1](../../assets/mrcoding/2021/03/image-2.webp)

```css
.slick-dots li button:focus:before, .slick-dots li button:hover:before{
    opacity: 0.25 !important ;
}
.slick-dots li.slick-active button:before {
    opacity: 1 !important;
}
```

這個現象是當時在手機上觀察到的，是因為CSS class的 優先權出現問題導致的，在PC 上看起來正常，所以請把上述的CSS 加上去，即可

> Version note / 版本註記：這是 2021 年所遇到的 Slick 樣式狀態。`:focus`／`:hover` 的圓點可能看起來與 active 相同，不代表真的有兩個 active slide；上例只調整外觀。套件、主題或輸入方式不同時，應先檢查實際 CSS，並保留可辨識的鍵盤焦點樣式。

堪誤參考：[官方文件](https://github.com/kenwheeler/slick/blob/master/slick/slick-theme.scss)。
