持續更新中，如果有寫錯的地方歡迎糾正，謝謝各位。以下是基本語法對照，程式片段需要放在各語言合適的函數或類別中。

| 項目 | C | C++ | Java | C# | Python 3 |
| --- | --- | --- | --- | --- | --- |
| 引用 | `#include <stdio.h>` | `#include <iostream>` | `import java.util.List;` | `using System;`（組件／套件參考另行加入） | `import os` |
| 常見進入點 | `int main(void)` | `int main()` | `public static void main(String[] args)` | `public static void Main(string[] args)` | 從模組最上層依序執行 |
| 區塊 | 大括號 | 大括號 | 大括號 | 大括號 | 冒號與縮排 |
| 省略明寫型別 | 一般宣告需指定型別 | C++11 起可用 `auto` 推導 | Java 10 起區域變數可用 `var` | 區域變數可用 `var` | 直接賦值，動態型別 |
| 整數 | `int` | `int` | `int` | `int` | `int` |
| 浮點數 | `float / double` | `float / double` | `float / double` | `float / double` | `float` |
| 字串 | 字元陣列或指標，例如 `char s[] = "hi";` | `std::string` | `String` | `string` | `str` |
| 字元 | `char` | `char` | `char` | `char` | 沒有獨立 char 型別，用長度 1 的 str |
| 單行註解 | C99 起 `//` | `//` | `//` | `//` | `#` |
| 多行註解 | `/* ... */` | `/* ... */` | `/* ... */` | `/* ... */` | 每行加 `#`；三引號是字串，並非註解語法 |
| 布林 and / or / not | `&& / \|\| / !` | `&& / \|\| / !` | `&& / \|\| / !` | `&& / \|\| / !` | `and / or / not`（`&`、`\|` 是位元運算） |
| 印出文字 | `printf("Hello world\n");` | `std::cout << "Hello world" << std::endl;` | `System.out.println("Hello world");` | `Console.WriteLine("Hello world");` | `print("Hello world")` |
| 條件判斷 | `if (...) {} else if (...) {} else {}` | 同 C | 同 C | 同 C | `if ...: / elif ...: / else:`，各區塊要縮排 |
| 迴圈 | `while`、`do...while`、`for` | 同 C；另有範圍 for | `while`、`do...while`、`for`、`for (Type item : items)` | `while`、`do...while`、`for`、`foreach` | `while`、`for item in items:` |
| 函數／方法示例 | `int add(int a, int b) { return a + b; }` | 同 C（成員函數存取權另設） | `public int add(int a, int b) { return a + b; }` | `public int Add(int a, int b) { return a + b; }` | `def add(a, b):` 下一行縮排 `return a + b` |

C／C++／Java／C# 的字串使用雙引號，單引號通常表示字元；Python 兩者都可表示字串。

本文年代的 Python 沒有 switch；Python 3.10 起加入的是 `match / case` 結構式樣比對，與 C 系列 switch 的規則不同。

C++ 的 auto、Java／C# 的 var 都是在編譯期推導固定型別，不等同 Python 變數可改指向不同型別的物件。
