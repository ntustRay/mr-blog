HTML5 `<video>` 可以用 `playbackRate` 設定播放速度，播放器本身也可能覆寫這個值。這裡把輸入限制在 0.25～4 倍方便示範；MDN 提到的是部分瀏覽器在此範圍外可能靜音，並不是所有瀏覽器統一的規範範圍。

```html
    <h3>Video加速</h3>
    <video width="400" controls>
      <source
        src="https://www.w3schools.com/html/mov_bbb.mp4"
        type="video/mp4"
      />
    </video>
    <br />
    <button onclick="myFunction()">按我加速</button>
  <script>
    function myFunction() {
      const raw = prompt("請輸入影片速度（0.25～4）", "1.5");
      if (raw === null) return;
      const rate = Number(raw);
      const video = document.querySelector("video");
      if (video && Number.isFinite(rate) && rate >= 0.25 && rate <= 4)
        video.playbackRate = rate;
    }
  </script>
```
