在Chrome跟 safari上 已經淘汰很多過時的meta 的屬性了，某些特定的都是在IE7以下，才會正常顯示出來，為了避免這種事情發生! 趕快來學新的語法吧!

#### 編碼方式

```html
<meta http-equiv="Content-Type" content="text/html; charset=UTF-8" />
<!-- 檔案實際編碼及 HTTP Content-Type 也應一致使用 UTF-8 -->
可簡化為:
<meta charset="utf-8" /> 
```

#### 圖示相關

```html
網頁左邊icon:
<link rel="icon" href="/favicon.png" /> 
如果可以安裝成 APP 
IOS上圖示:
<link rel="apple-touch-icon" href="/logo192.png" />
手機上圖示:
<link rel="manifest" href="/manifest.json" />
```

#### 瀏覽整頁的大小

```html
<meta name="viewport" 
   	content="width=device-width, initial-scale=1" />
```

#### 設定快取與 Cookie

快取應由伺服器回傳 HTTP header 設定，不能把 `<meta http-equiv="Cache-Control">` 當作等效、可靠的作法：

```http
Cache-Control: no-store
```

`no-store` 不儲存回應；`no-cache` 允許儲存，但重用前必須驗證；`must-revalidate` 表示過期後不可未經驗證就重用。

`<meta http-equiv="Set-Cookie">` 已被瀏覽器忽略；請用伺服器的 `Set-Cookie` 回應標頭或適用情境下的 `document.cookie`。

#### 每隔一段時間重新整理，秒數後分號導向某個網頁

```html
<meta http-equiv="Refresh" content="2;URL=http://www.51siny.com/" />

手機上address bar可以更改顏色
<meta name="theme-color" content="#000000" />
```

#### 手機上address bar可以更改顏色

```html
<meta name="theme-color" content="#000000" />
```

#### 搜尋引擎相關

```html
<meta name="description" content="Web site NEW BEE" />
在搜尋引擎上 會跳出的小字描述。
<meta name="keywords" content="關鍵字"/>
<!-- Google 搜尋不使用 keywords meta 作為網頁排名依據 -->
<meta name="robots" content="index, follow"> 
<!-- all 是 Google 支援的值，等同不限制索引與連結追蹤，通常不必特別寫 -->
```

##### `<meta name="viewport">` 參數表格

| 參數 | 值 | 描述 |
| --- | --- | --- |
| `width` | 正整數或 `device-width` | 以pixels為單位， 定義viewport的寬度。 |
| `height` | 正整數或 `device-height` | 以pixels為單位， 定義viewport的高度。 |
| `initial-scale` | `0.0` ~ `10.0` | 定義設備寬度與視口大小之間的縮放比率。 |
| `maximum-scale` | `0.0` ~ `10.0` | 定義縮放的最大值；它必須大於或等於`minimum-scale`的值，不然會導致不確定的行為發生。 |
| `minimum-scale` | `0.0` ~ `10.0` | 定義縮放的最小值；它必須小於或等於`maximum-scale`的值，不然會導致不確定的行為發生。 |
| `user-scalable` | `yes` / `no` | 如果設置為` no`，用戶將不能放大或縮小網頁。默認值為` yes`。 |

### 舊式寫法與常見誤解

```html
<meta name="MSSmartTagsPreventParsing" content="true"> <!-- 舊 Microsoft Smart Tags 相關用法，現代瀏覽器不採用 -->
<meta name="robots" content="all"> <!-- 有效，不屬於過時語法 -->
<meta name="copyright" content="…"> <!-- 可作自訂中繼資料，非通用 SEO 指令，也不產生版權保護效果 -->
<meta name="rating" content="…"> <!-- 非通用標準；個別服務可能定義用途，不能一概說不存在 -->
<meta http-equiv="Page-Enter" content="">  IE only
<meta http-equiv="Page-Exit" content=""> IE only
<meta http-equiv="Content-Language" content="zh-Hant-TW" /> <!-- 過時，請用 <html lang="zh-Hant-TW"> 指定文件語言 -->
```

不建議以 `user-scalable=no` 禁止縮放，會妨礙需要放大文字的使用者；瀏覽器也可能忽略此限制。
