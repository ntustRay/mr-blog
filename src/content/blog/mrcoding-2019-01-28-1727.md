### ~~*不引用馬超/馬謖/馬X/賈X斯/比爾X/柏X圖/笛X爾 說過的話*~~  
***「自己的觀念、自己的經驗、自己的slogan，自己說。」***

1.記錄生活

大家都知道寫日記的優點在此就不詳述，寫blog亦是如此，但日記可能會弄丟不見，經過歲月洗禮而泛黃，但在blog寫只要你有備份好，到哪裡你的紀錄都會存在，我小六申請留言板也還在，~~但我小六寫給別人的情書卻不在了~~，所以寫BLOG跟網站保存容易，是比寫實體日記更好的優點之一

2.增加競爭力

一但把你的想法，作品內容就登錄到網路上，你就不怕你作品忘記或忘了放到哪裡去，哪怕是你的詩及，想的詞哼的曲，到作畫都可以掃描post上來，到時候你工作給作品，不但有個人網頁還有blog，呈現你的作品給別人看也相當容易

3.成就感

大家都知道寫程式成功編譯跑出來的時候最欣喜若狂，改BUG的時候心如死灰，但寫網頁跟BLOG好處，如果你寫js+html+css，且有js離線libray ，就可以直接用txt開始寫網頁，不論是在Mac、微軟、手機、Linux，只要瀏覽器開得起來，馬上就可以呈現出你要的效果，不需另外安裝其他軟體，可以快速得到類似寫程式的成就感唷！而且很多程式的美編及視覺化是一大問題，但網頁因為就是要人看的，視覺美化相對來說是比較容易，你不喜歡寫高深的function但也可以把你的網頁用的美美的展現藝術天分。

4.知道自己的不足

寫blog開啟留言功能，一但愈多人看見，就會幫忙你修正你文章錯誤的地方或文筆，會提出問題或建議，如果別人發問你回答不出來，你就可以去精進你不足的地方（有時間的話XD）這樣跟大家一來一往的互動，就像是跟虛擬的同學請教一樣，我認為是對進步有大大益處的。

5.避免無名小站的悲劇

我選擇開源的WP，來寫blog，就代表可以隨時隨地邊改，任意寫程式碼或備份，就不會像小時候無名小站部落格倒了，你只能用笨笨的方法來備份你的圖片跟文章，卻不能重現無名部落格的形式，而現在blog你只要有備份檔，自己架伺服器也可以重現往日的部落格架構，放到哪你的形式都不會改變 ( 除非開始不用 js php html css mysql )，所以大家不用太擔心。
