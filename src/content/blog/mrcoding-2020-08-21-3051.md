localStorage 跟 sessionStorage 的方法與屬性一致，都是依 origin（協定、主機、連接埠）區分的字串鍵值儲存。localStorage 通常跨瀏覽器工作階段保留，沒有內建到期時間，但使用者、隱私模式或瀏覽器政策仍可能清除；sessionStorage 另外依分頁區分，通常在分頁的工作階段結束後清除，重新整理仍會保留。它們不是 HTTP cache，也不保證永久保存。

| localStorage | sessionStorage |
| --- | --- |
| 通常持續保存，直到被清除 | 只要把整個分頁關掉，  <br>就會刪除資料。 |

## 屬性

`Storage.length` Read only返回一數字，代表儲存在 `Storage` 中的物件的數量。

## 方法

- `Storage.key()` - 當傳入一數字 `n`, 會返回 storage 裡第 n 個值的 key 值。
- `Storage.getItem()` - 當傳入一 key 值, 會返回 storage 裡此 key 值對應的 value 。
- `Storage.setItem()` - 當傳入 key 及 value 的值, 會在 storage 裡新增此 key 及 value 值，若 key 已存在，則會把值更新成傳入的 value。
- `Storage.removeItem()` - 當傳入一 key 值, 會把此 key 從 storage 裡刪除。
- `Storage.clear()` - 執行此方法，會刪除所有在 storage 裡的 key。

## 範例:

```html
<button onclick="localSave()">儲存 localStorage</button>
```

你曾經按過幾次按鈕: 0

```html
<button onclick="clearLocal()">清空 localStorage</button>
```

  

```html
<button onclick="sessionSave()">儲存 sessionStorage</button>
```

你曾經按過幾次按鈕: 0

```html
<button onclick="clearSession()">清空 sessionStorage</button>
```

```html
<script>
 let preLocalCount = localStorage.getItem('count');
 let preSessionCount = sessionStorage.getItem('count')

 if(preLocalCount)
   document.getElementById('result1').textContent = preLocalCount;
 if(preSessionCount)
   document.getElementById('result2').textContent = preSessionCount;

 function localSave () {
   preLocalCount = localStorage.getItem('count');
   if(!preLocalCount) 
     preLocalCount = 0;
   localStorage.setItem('count', parseInt(preLocalCount) + 1)
   document.getElementById('result1').textContent = localStorage.getItem('count');
 }

 function sessionSave () {
   preSessionCount = sessionStorage.getItem('count');
   if(!preSessionCount) 
     preSessionCount = 0;
   sessionStorage.setItem('count', parseInt(preSessionCount) + 1)
   document.getElementById('result2').textContent = sessionStorage.getItem('count');
 }
  
 function clearLocal () {
 	localStorage.removeItem('count');
    document.getElementById('result1').textContent = 0; 
 }
 
 function clearSession () {
 	sessionStorage.removeItem('count');
    document.getElementById('result2').textContent = 0; 
 }
 
</script>
```

值會以字串保存；儲存物件時需搭配 `JSON.stringify`／`JSON.parse`。兩者都能被同源 JavaScript 讀取，不適合保存密碼；寫入也可能因容量或瀏覽器設定而失敗。
