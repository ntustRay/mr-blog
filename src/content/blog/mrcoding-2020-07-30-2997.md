```javascript
const constraints = { //相機限制
  audio: false,
  video: {
    facingMode: "user"  //開前鏡頭
  }
};

const getCameraStream = video => { //要 camera 的權限
  return navigator.mediaDevices
    .getUserMedia(constraints)
    .then(function success(stream) {
      video.srcObject = stream;
    });
};
```

需在 HTTPS 或 localhost 使用，並由使用者允許相機權限。傳入的 `video` 可設定 `autoplay`、`muted`、`playsInline`；呼叫端要處理 Promise 拒絕（例如使用者拒絕或找不到相機），使用完再對 `video.srcObject.getTracks()` 的每個 track 呼叫 `stop()`。
