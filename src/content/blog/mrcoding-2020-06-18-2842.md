#### **新手必學，若還不知道，把握機會!**

一般來說，我們都會用 function + name ，去建立一個函式，但現在ES6特性，可以用一種更方便的寫法來改寫

```jscript
//原型:
function myfun(x, y){
  var a = x + y;
  return a;
}
```

改寫寫法：

```javascript
const myfun = (x, y) => { 
  var a = x + y;
  return a;
}
```

其中若只有單一參數，括號可以去除：

```javascript 
const myfun = x => { 
  var a = x + x;
  return a;
}
```

只有一個回傳運算式時，以下兩段也可以互相改寫：

```javascript
function myfun(x, y){
  return x + y;
}
```

省略大括號與 return：

```javascript
const myfun = (x, y) => x + y;
```

學會箭頭函式，一切都會變很美好，如果還是只會原本的function  
你看現在三大架構的程式碼會很痛苦，因為現在他們幾乎都用ES6以上特性去寫了  
(react、vue、angular)

補充：箭頭函式沒有自己的 `this`、`arguments`，也不能當建構函式使用，因此不能把所有 `function` 都直接替換成箭頭函式。
