這邊使用，test這個方法作為判斷依據，使用正規表達式，來運算()裡面的字串，是否有/ /中的規則。

[MDN test詳解](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Global_Objects/RegExp/test)

iPadOS 在部分模式會使用像 Mac 的 user agent，因此只檢查 `iPad` 會漏掉裝置。user agent 本來也不能可靠識別 iPhone 11／12 等型號；`TouchEvent` 並非 iOS 專屬，不能拿它當作保證。

下例保留 UA 判斷的方向，並用 Mac 標記加多點觸控作 iPad 的啟發式補充；仍可能誤判。若需求是版面或觸控操作，請改檢測對應功能。

```javascript
const detectBrowser = {
  isIpad: () => /iPad/i.test(navigator.userAgent) ||
    (/Macintosh/i.test(navigator.userAgent) && navigator.maxTouchPoints > 1),
  isIOs: () => /iPad|iPhone|iPod/.test(navigator.userAgent) ||
    (/Macintosh/i.test(navigator.userAgent) && navigator.maxTouchPoints > 1)
};

detectBrowser.isIOs() // true or false
```
