這邊幫大家整理 for in vs for of vs foreach

1. for in 取得 array 或 object 可列舉的字串 key，包含原型鏈上的可列舉屬性；陣列通常用 for of 或 forEach 比較直覺
2. for of 取得的是值，但一般沒有 iterator 的物件不能直接使用
3. forEach 的 callback 可取得 value、index；不能用 break 中止整個迭代。callback 裡可以 return，但只結束該次 callback，不會離開外層函式。

|  | for in of | foreach |
| --- | --- | --- |
| break | Y | N |
| return 離開外層函式 | Y（須在函式內） | N（只離開 callback） |

|  | for in | for of | foreach |
| --- | --- | --- | --- |
| 迭代指 iterator 的值 | index | value | index / value |
| 可直接用在 object上 | Y | N | N |

而 for of / foreach 若要巡覽object中的各值，  
則要用到Object物件把object轉成array，有以下三種方法

1. Object.values()
2. Object.keys()
3. Object.entries()

範例程式代碼:

```javascript
let array = [3, 5, 7];

// 回傳「key」
for (let i in array) {
  console.log(i); // "0", "1", "2"
}

// 回傳「value」
for (let i of array) {
  console.log(i); // 3, 5, 7
}

array.foo = 'hello';   //新增foo屬性名稱

//會讀取到陣列新增的屬性名稱
for (let i in array) {
  console.log(i); // "0", "1", "2", "foo"
}

//不會
for (let i of array) {
  console.log(i); // 3, 5, 7
}

const object1 = {
  a: 'somestring',
  b: 42
};

//for of 迭代object的方法
for (const [key, value] of Object.entries(object1)) {
  console.log(`${key}: ${value}`);
}
// a: somestring
// b: 42

//foreach 基本用法
array.forEach((value, index, arrayPointer) => {arrayPointer[index] = value + 1;});
array; // [4,6,8]


const obj = {
  name: 'Jean-Luc Picard',
  rank: 'Captain'
};

//foreach 迭代object的方法
Object.keys(obj).forEach(key => {
  console.log(key, obj[key]);
});
//name, Jean-Luc Picard
//rank, Captain

Object.values(obj).forEach(val => {
  console.log(val);
});
//Jean-Luc Picard
//Captain

Object.entries(obj).forEach(entry => {
  const [key, value] = entry;
  console.log(key, value);
});
//name, Jean-Luc Picard
//rank, Captain
```
