type = radio ，且 name屬性要一致，就可以變成單選問卷

```jsx
    <div>
      <p>Title</p>
      1. <input type="radio" name="question" value={1} />
      2. <input type="radio" name="question" value={2} />
      3. <input type="radio" name="question" value={3} />
    </div>
```

範例:

Title

 1 

```html
<input type="radio" name="GG">
```

 2 

```html
<input type="radio" name="GG">
```

 3.

```html
<input type="radio" name="GG">
```
