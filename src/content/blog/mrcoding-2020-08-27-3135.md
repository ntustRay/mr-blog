快速教大家如何用 UseEffect 增加事件吧!

```javascript
 useEffect(() => {
    const myfunc = () => console.log('trigger');
    window.addEventListener("scroll", myfunc);
    return () => {
      window.removeEventListener("scroll", myfunc);
    };
  }, []);
```

這個 handler 不使用 props 或 state，空依賴陣列即可；若之後需要讀取會改變的值，必須一併處理 Effect 依賴，避免沿用舊的閉包。

堪誤參考：[官方文件](https://react.dev/reference/react/useEffect)。
