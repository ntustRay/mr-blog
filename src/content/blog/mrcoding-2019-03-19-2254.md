可以分成以下幾點來討論

|  | class | struct |
| --- | --- | --- |
| 型別語意 | 引用型別 | 值型別 |
| 建構子 | 可以宣告無參數建構子 | 2019 年的 C# 版本不能自行宣告無參數建構子，但有預設初始化；C# 10 起可宣告 public 無參數建構子，仍不能宣告解構子 |
| 執行個體欄位初始化 | 可在宣告時指定初值 | C# 10 以前不能在宣告時指定初值；C# 10 起可搭配明確宣告的建構子使用 |
| 繼承 | 可繼承一個類別（含抽象類別），並實作多個介面 | 不能繼承其他 class/struct，也不能作為其他型別的基底；可實作介面 |
| 成員預設存取權限 | private | private |
| 儲存位置 | 依實作與使用情境決定 | 依實作與使用情境決定，不保證位於 stack |

這會造成，如果把class 或 struct建構的實例丟進方法裡面去計算會有所不同

預設按值傳參數時，class 複製的是物件參考，兩邊仍指向同一個物件；struct 複製的是值。若 struct 裡含有參考型別欄位，複製後那些欄位仍可能參考同一個物件。

而何時使用 struct 呢？以下整理早期 MSDN 的設計建議，屬於選型參考，不是語言限制：

**✓ CONSIDER** 定義而不是類別結構，如果執行個體類型的小，通常存留較短或嵌入其他物件。

**X AVOID** 定義結構，除非該類型具有所有下列特性：

- 它以邏輯方式表示的單一值，類似於基本型別 (`int`， `double`，依此類推。)。
- 它具有執行個體大小小於 16 個位元組。
- 它永遠不變。
- 它不會經常 boxed。
