以下是 React Router v5 的傳值寫法，`Route` 需放在 Router 之內。React Router v6/v7 改用 `Routes` 及 `element` 等 API，不能直接套用本文的 `component`／`render` 寫法。

基本傳值法

```javascript
<Route path='/dashboard'>
  <Dashboard isAuthed={true} />
</Route>
```

錯誤

```javascript
<Route path='/dashboard' component={Dashboard} isAuthed={true} />
```

可以渲染，但不建議傳入 inline function 給 component；父層每次渲染都建立新的函式型別，可能造成子元件重新掛載及狀態重設。

```javascript
<Route path='/dashboard' component={() => <Dashboard isAuthed={true} />} />
```

在 v5 需要 inline function 並傳入路由 props 時，使用 render 可避免上述重新掛載問題：

```javascript
<Route path='/dashboard'render={(props) => <Dashboard {...props} isAuthed={true} />} />
```
