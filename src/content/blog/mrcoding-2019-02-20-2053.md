auto 會自動依賦予的變數值給予變數類型。

語法看起來像 Python 直接賦值，但 C++ auto 是編譯期型別推導；宣告後型別固定，不是動態型別。

而auto 也可以用在方法的回傳值，這種省略尾置回傳型別的推導用法從 C++14 起支援，後續版本也可用  
這樣就可以不用預設你這個方法到底要回傳什麼類型的變數，增加coding彈性

```cpp
#include <iostream> 
#include <cmath> 
#include <typeinfo>
 
using namespace std;
 
auto autofun() {
  auto value = 3.1415;
  return value;
}
 
 
int main() {
   auto x = 12;
   auto y = sin(1.3);
  cout << "Hello World!\n "<<"X: "<< x <<" Y: "<< y << endl;
  cout << "X變數類型: "<< typeid(x).name() <<" Y變數類型: "<< typeid(y).name() <<endl;
  cout << autofun();
}
```
