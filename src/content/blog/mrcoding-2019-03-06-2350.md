接下來是array的用法  
陣列屬性可以用 `customer.BuyList[i]` 存取元素；若希望直接使用 `customer[i]`，則可定義索引子（indexer），以下為範例。

```csharp
public class Customer {
    private double[] buylist = new double[10];
    public string CustomerName { get; set; }

    public double[] BuyList {
        get { return buylist; }
        set { buylist = value; }
    }

    public double this[int i] { // 索引子
        get { return buylist[i]; }
        set { buylist[i] = value; }
    }
}

class Store {
    public static void Main() {
        Customer customer = new Customer();
        customer[5] = 60; // 使用中括號，並先確保底層陣列有配置空間
    }
}
```
