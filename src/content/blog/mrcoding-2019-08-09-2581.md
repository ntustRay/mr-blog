Map 跟List和 Set不同，不屬於Collection下的child interface  
Map有Key跟Value組成一對。  
而Key有唯一性，若新增同一個key有不同的value，會把原先key值的資料蓋過去。  
類似C#跟Python辭典的功能

Map又分為 HashMap 、Hashtable、TreeMap、LinkedHashMap等等

| HashMap | Hashtable |
| --- | --- |
| 非同步 | 同步（方法層級具執行緒同步） |
| 效率好 | 效率較差 |
| Key跟Value可以為null | 皆不能為null |

```java
import java.util.HashMap;
import java.util.Map;

// 以下敘述放在方法內
HashMap<String, Integer> map1 = new HashMap<String, Integer>();
map1.put("score", 80);
map1.containsKey("score"); // 檢查是否存在 key
map1.size();
map1.get("score");
map1.keySet();
map1.values();

for (Map.Entry<String, Integer> m : map1.entrySet()) {
    System.out.println(m.getValue());
    System.out.println(m.getKey());
}
```

範例

```java
import java.util.Hashtable;

public class MapTest1 {
	public static void main(String[] args) {
		Hashtable map1 = new Hashtable(); 
		map1.put("name", "Brad");
		map1.put("weight", 80.4);
		map1.put("length", 176);
		map1.put("length", 180); // 身高原本176會被覆蓋成180

		//map1.put(null, 17);//會跳例外
		//map1.put(12, null);//會跳例外	

		System.out.println(map1.size());
	}
}

```

以下是另一個獨立檔案的範例：

```java
package hackerrank; //這是hackerrank的Map範例 要找出貨物成對的組數

import java.util.*;

public class SockMerchant {
	public static void main(String[] args) {

		int[] ar = { 10, 20, 20, 10, 10, 30, 50, 10, 20 }; //這邊把貨物的每個數值當成唯一key
		int n = ar.length;
		int ans = newsolution.sockMerchant(n, ar);
		System.out.println(ans);

	}
}

class newsolution {
	static int sockMerchant(int n, int[] ar) {

		int pairsNums = 0;

		HashMap<Integer, Integer> hm = new HashMap<Integer, Integer>();//可以指定key跟value的型態

		for (int i : ar) {
			if (!hm.containsKey(i)) {  //是否有重複
				hm.put(i, 1);
			} else {
				hm.put(i, hm.get(i) + 1); //重複後 key裡的值+1 
			}
		}
		//System.out.println(hm.keySet()); //取得全部的key值
		//System.out.println(hm.values()); //取得全部key的value	
		for (HashMap.Entry<Integer, Integer> m : hm.entrySet()) { //尋覽map的方法
			if (m.getValue() >= 2) { 
				pairsNums += (int) m.getValue() / 2;
			}
		}
		return pairsNums;
	}
}
```
