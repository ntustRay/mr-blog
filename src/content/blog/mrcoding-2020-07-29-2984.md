```clike
using System;

class MainClass {
  public static void Main (string[] args) {
    String str1 = "我好帥";
    String str2 = "我好醜";
    String str3 = "我好帥";
    char[] chrArray = { '我', '好', '帥' };
    string str4 = new string(chrArray);
    Console.WriteLine(str1==str3); //true
    Console.WriteLine(str1==str4); //true
    Console.WriteLine(str1.Equals(str3)); //true
    Console.WriteLine(str1.CompareTo(str2)); // 負數、0 或正數取決於目前文化特性的排序規則
    Console.WriteLine(str1.CompareTo("我好帥")); // 0
    Console.WriteLine(str1.CompareTo("他比醜我好帥")); // 依目前文化特性的排序規則決定
  }
}
```

和 Java 不同，當兩側的靜態型別都是 C# `string` 時，`==` 會比較字串內容。`CompareTo` 用來比較排序，只保證回傳負數、0 或正數，不保證一定是 -1／1。

## ***注意!!!!!***

數值經 `ToString()` 轉成字串後，只要字串內容相同，使用 `string == string` 一樣會是 `true`，與是否由數值轉換而來無關。若把字串裝在 `object` 變數中再用 `==`，才可能變成參照比較。需要固定比較規則時，可使用 `string.Equals(a, b, StringComparison.Ordinal)`；數值格式仍受指定的文化特性影響。
