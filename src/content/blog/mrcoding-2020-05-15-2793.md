方法 1. performance

```javascript
const t0 = performance.now();
doSomething();
const t1 = performance.now();
console.log(`Call to doSomething took ${t1 - t0} milliseconds.`);
```

方法 2. console

```javascript
let arr = [];
for(let i = 0 ; i < 100000; i++  ){
	arr.push(Math.random());
}
console.time("sort");
arr.sort((a, b) => a - b); // 數值由小到大排序
console.timeEnd("sort");
```

performance   
`performance.now()` 回傳相對於 time origin 的單調遞增時間戳（毫秒），可用前後差值估算經過時間  
所以可以拿來判斷程式執行的時間。  
判斷效率非常好用的一個方法喔!

Console: 簡單用易用

若 `doSomething()` 是非同步函式，上例只量到同步呼叫的時間；要量到非同步工作完成，需在 async 函式內使用 `await doSomething()` 再取得 t1。單次數值也會受 JIT、系統負載與計時精度限制影響。
