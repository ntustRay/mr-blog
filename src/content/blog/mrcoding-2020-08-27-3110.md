下command line

1. npm rm -g create-react-app
2. npx create-react-app@latest my-app

```powershell
npm rm -g create-react-app
npx create-react-app@latest my-app
```

參考:

[https://stackoverflow.com/questions/59260031/public-src-and-scripts-folder-not-created-while-using-create-react-app](https://stackoverflow.com/questions/59260031/public-src-and-scripts-folder-not-created-while-using-create-react-app)

當時官方建議移除舊的全域 `create-react-app`，讓 `npx` 使用對應版本；不需移除後又全域安裝。若建立失敗，還要查看 npm 錯誤輸出，缺少 `src` 本身不能證明只有一種原因。

> 版本註記：Create React App 已於 2025 年被 React 官方棄用於新專案；以上保留為舊專案排錯紀錄，新專案請依官方安裝文件選擇工具。
