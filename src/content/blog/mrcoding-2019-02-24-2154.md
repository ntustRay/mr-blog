> finalize 是舊版 Java 的歷史範例，已被棄用並列為待移除。不要用它管理必要清理；下方 OUTPUT 只是其中一次觀察，訊息可能不出現。

筆記：

JVM本身就有記憶體回收機制，我看大家都沒有特殊用途不用特別釋放記憶體  
但還是學一下基本的原理跟應用方式吧  

`System.gc()` 是向 JVM 請求進行垃圾回收，不保證特定物件立即回收，也不保證釋出特定大小的記憶體。檔案、網路連線等資源仍應用 try-with-resources 等方式明確關閉。

```java
package 課程1;

public class runtime {

    public static void main(String[] args) {

        Runtime rt = Runtime.getRuntime();  //可以取得當前JVM的運行時環境

        System.out.println(rt.freeMemory()); //取得freeMemory

        for (int i = 0; i < 1000000; i++) {

            String Str = new String("sdd" + i); //不停生新物件佔據記憶體

            if (i == 500000) {
                System.out.println(rt.freeMemory()); //取得freeMemory
            }

        }

        TestGCannFinalize testGC = new TestGCannFinalize(); 

        testGC = null; //有沒用的物件了

        System.gc(); //提出回收請求；不保證下方 finalize 訊息會出現。 

    }

}

class TestGCannFinalize{
    {
        System.out.println("安安，我建置了");
    }

    protected void finalize() { //歷史示範：不保證何時呼叫或一定呼叫。
        System.out.println("被回收前，讓我寫一個慘字");
    }
}

/* 
OUTPUT :
-------
每台電腦不同
509461096
474427736
安安，我建置了
被回收前，讓我寫一個慘字
 */
```
