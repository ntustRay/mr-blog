今天就給大家分享 python 3.x版的 寫讀檔+暫停+離開

```python
import sys

# 暫停~~

# 以下為寫檔 a為繼續寫 w 為重寫覆蓋 r 閱讀模式

fpw = open("檔名或路徑", "a", encoding="utf-8") 

fpw.writelines("1234") #寫入

fpw.close() #關閉

#以下為讀檔示範

fpr = open("檔名路徑", "r", encoding="utf-8")

line = fpr.readline()
print ("內容: "+line)

fpr.close()

input("按 Enter 繼續…")

#正常結束程式

sys.exit(0)

```
