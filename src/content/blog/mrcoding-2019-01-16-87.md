> 以下以 Visual Studio 的預設鍵盤配置為主。Alt + Shift + F 是 VS Code 在 Windows 的格式化快捷鍵，兩個軟體不要混用。

以下是常用的快捷鍵!  
供大家參考

| 1.自動排版 | Ctrl + K，接著 Ctrl + D |
| --- | --- |
| 2.註解 | Ctrl + K，接著 Ctrl + C |
| 3.取消註解 | Ctrl + K，接著 Ctrl + U |
| 4.反白區塊轉為大寫 | CTRL + SHIFT + U |
| 5.反白區塊轉為小寫 | CTRL + U |
| 6.減少縮排 | SHIFT + Tab |
| 7.查看定義 | F12 |

勘誤參考：[Visual Studio 預設快捷鍵](https://learn.microsoft.com/en-us/visualstudio/ide/default-keyboard-shortcuts-in-visual-studio?view=vs-2022)。
