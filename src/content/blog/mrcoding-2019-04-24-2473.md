| 型態 | FileStream (I/O) | DataStream(I/O) | FileRead (W/R) | ObjectStream (OI/OO) |
| --- | --- | --- | --- | --- |
| 輸入／輸出類型 | byte | 基本型別及特定字串格式 | char | 可序列化的物件與基本型別 |

因各種IO串流不同，導致有不同結果

可以直接在txt或用字元行是打開閱讀的，用 W/R

有些處理byte用 FileStream ，但未必能在記事本打開直接順利閱讀(除非輸入字串或字元)  

DataInputStream／DataOutputStream 提供 int、boolean 等基本型別與字串的二進位讀寫方法，不是任意類別都能直接寫入；讀取順序及型別必須與寫入一致。即使使用 writeUTF，仍有長度資訊，不等同一般 UTF-8 純文字檔。

ObjectInputStream／ObjectOutputStream 用來讀寫可序列化的物件，也是不錯的一個選項

```java
package iotest;

import java.io.*;

public class DataStream {

	public static void main(String[] args) throws Exception {
		
		FileOutputStream fout = new FileOutputStream("./newfolder/file3_dataStream");
		DataOutputStream Dout = new DataOutputStream(fout);
		
		int a = 9453;
		byte b = 87;
		boolean c = false;
		
		Dout.writeInt(a);
		Dout.writeByte(b);
		Dout.writeBoolean(c);
		
		Dout.flush();
		Dout.close();
		
		FileInputStream fin = new FileInputStream("./newfolder/file3_dataStream");
		DataInputStream din = new DataInputStream(fin);
		
		System.out.println(din.readInt());
		System.out.println(din.readByte());
		System.out.println(din.readBoolean());
        din.close();
		

	}

}
```
