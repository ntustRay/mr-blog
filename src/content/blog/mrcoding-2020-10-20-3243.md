1. 在createContext()時初始化
2. context.provider value = {state}時給值

---

[相關文章](../mrcoding-2020-10-20-3240/)

```jsx
//在createContext()時初始化
import React from 'react'

const state = { name: 'Tania', loggedIn: true }

const UserContext = React.createContext(state)
export default UserContext
```

```jsx
//context.provider value = {state}時給值
import React from 'react'
import HomePage from './HomePage'
import UserContext from './UserContext'

function App() {
  const user = { name: 'Tania', loggedIn: true }

  return (
    <UserContext.Provider value={user}>
      <HomePage />
    </UserContext.Provider>
  )
}
```

`createContext(defaultValue)` 的值是在上方找不到對應 Provider 時的預設值，不是可更新的 state 初始化；若 Provider 存在，會讀取它的 `value`。自訂 `UserProvider` 元件只有在自己轉傳 `value` 時才會採用該 prop。

堪誤參考：[官方文件](https://react.dev/reference/react/createContext)。
