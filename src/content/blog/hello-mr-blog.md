這是 **MR Blog** 的第一篇文章。

我希望這裡保持簡單：文章用 Markdown 撰寫，網站交給 Astro 產生靜態頁面，再由 GitHub Pages 免費託管。

## 為什麼選 Astro？

目前的需求其實很單純：

- 以文章內容為主
- 使用 TypeScript 生態
- 保持網站快速
- 不需要額外 Server
- 可以直接部署到 GitHub Pages

Astro 很適合這種 content-first 的網站，而且之後如果真的需要互動功能，仍然可以加入 React component，不需要現在就把整個 Blog 做成複雜的 Web App。
