匯出範例（`tools.js`）：

```javascript
const fs = {};
export default fs;
export const version = "1.0";
export function readFile() { return "example"; }
function read() { return "example"; }
export { read };
// 轉匯出其他模組的具名匯出，不包含 default：
export * from './other.js';
```

匯入寫法（每行是獨立選項，不要全部貼在同一個檔案重複宣告）：

```javascript
import fs from './tools.js';
```

```javascript
import { default as fs } from './tools.js';
```

```javascript
import * as fs from './tools.js'; // namespace 物件，不等同於 default
```

```javascript
import { readFile } from './tools.js';
```

```javascript
import { readFile as read } from './tools.js';
```

```javascript
import fs, { readFile } from './tools.js';
```

`export const` 需要初始值，`export function` 需要參數與函式內容；不是省略後也能執行的語法。Node.js 的 `fs` 是內建模組，不能直接假設瀏覽器也有。

堪誤參考：[MDN 文件](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/export)、[MDN 文件](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/import)。
