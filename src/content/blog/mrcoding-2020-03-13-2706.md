## 591網看屋時勾選

### 基本

- [ ] 照片4張以上至少包含廁所跟房間各角落
- [ ] 照片能看出實際屋況，並在現場對照；修圖或布置本身不能直接證明房況好壞
- [ ] 說明各項費用 (如水電網路管理費等)
- [ ] 非房仲(會多抽錢，可能房仲人好，房東耍廢)
- [ ] 非頂加、地下室
- [ ] 有對外窗
- [ ] 桌子
- [ ] 網路
- [ ] 熱水
- [ ] 冷氣
- [ ] 床 (加分，因為地板直接撲上床墊也是可以睡)
- [ ] 中華電信光纖網路 30M以上

## 實際看屋時勾選

### 基本配備

- [ ] 桌子
- [ ] 網路
- [ ] 熱水
- [ ] 冷氣
- [ ] 床

#### 屋子結構

- [ ] 非頂加、地下室
- [ ] 走道不會潮濕陰暗
- [ ] 屋齡不能過高
- [ ] 有對外窗
- [ ] 有廁所窗 (廁所若沒對外窗至少要有抽風的)
- [ ] 為氣密窗(增加隔音)
- [ ] 為水泥牆
- [ ] 天花板非辦公室類型 (很少但很加分)
- [ ] 為鋼門 (木門或木牆隔音會很差)
- [ ] 窗戶沒面朝西邊  
  (下午看房可注意，西曬房間室內溫度夏天會最高，非頂加也會爆熱)

#### 費用

- [ ] 房租是否包含水費電網路第四台費
- [ ] 確認電費計收方式並索取電費資訊。2024 年 7 月 15 日起新簽的住宅租約若按度計費，每度不得超過該電費單的當期每度平均電價；不能單憑「5 元以下」判斷是否合理。
- [ ] 無管理費

#### 規定

- [ ] 可以帶異性進房間
- [ ] 朋友可以過夜
- [ ] 可以開火 (加分用)
- [ ] 不能養寵物 (養寵物會吵死)
- [ ] 垃圾有幫忙丟 (加分用)

#### 公共空間

- [ ] 曬衣空間 (能在自己房間最好)
- [ ] 洗衣機 (在自己房間更好)
- [ ] 飲水機 (加分用)

#### 人品驗證

- [ ] 坪數是否正確 (台北有通常會謊報多2坪以上)
- [ ] 房東應對態度 (太消極、太積極都很有問題)
- [ ] 是否跟房東同住 (同住房東很容易多管閒事)
- [ ] 是否有其他房客 (沒房客很詭異)
- [ ] 照片跟房間符合 (我遇過3次帶不同房間給我的都雷炸天)
- [ ] 房東年紀不會太大

#### 房子周邊環境

- [ ] 觀察鄰居及周邊出入情況；是否為事故屋應另外查證，不能從鄰居人數或眼光判定
- [ ] 非主要幹道旁 (大馬路旁雙層氣密式窗戶一樣吵死人，我看過這種房子)
- [ ] 有便利超商
- [ ] 有公車經過
- [ ] 有垃圾車經過 (要問清楚幾點來)
- [ ] 有捷運在附近 (加分用)
- [ ] 有機車停車格 (加分用)
- [ ] 有大賣場或超市 (加分用)
- [ ] 有小吃店或餐廳

## 簽約

- [ ] 是否已拍照或錄影存證房間環境  
  (張淑晶惡房東就是用破壞家具這招坑殺房客)
- [ ] 押金不能超過2個月 (同上會被坑殺)
- [ ] 簽約前看清合約書的價格與條款
- [ ] 有房東平常聯絡方式
- [ ] 取了鑰匙或要了電子密碼

這是 2020 年的個人看屋清單，其中設備與生活規定反映個人偏好，並非每間房屋都必須符合。住宅租賃的押金以不超過兩個月租金總額為原則；實際簽約請對照當時適用的住宅租賃契約規範。
