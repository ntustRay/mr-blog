今天快速整理一下，如何讓 svg 的檔 用js轉成 PNG檔  
這個方法需要 svg的整個 element來進行轉換，轉換後會自動下載

```javascript
  const svgToPNG = (svgElement) => {
    let svgData = new XMLSerializer().serializeToString(svgElement);
    //將svg資料序列化成 string
    let canvas = document.createElement( "canvas" ); 
    // 為了把 SVG 轉成 PNG 而建立 canvas
    let ctx = canvas.getContext( "2d" );

    let img = new Image();
    // 用百分比編碼保留中文；直接 btoa(svgData) 會因 Unicode 字元失敗
    
    img.onload = function() {
      canvas.width = img.width;
      canvas.height = img.height;
      ctx.drawImage( img, 0, 0 );
      
      let a = document.createElement("a");
      a.download = "QRcode.png";
      a.href = canvas.toDataURL( "image/png" );
      a.click();
    };
    img.onerror = () => console.error("SVG 載入失敗");
    img.src = "data:image/svg+xml;charset=utf-8," + encodeURIComponent(svgData);
  };
```

請替 SVG 指定明確寬高；外部字型、圖片與未內嵌的 CSS 不一定能跟著序列化，跨網域資源也可能讓 canvas 無法匯出。
