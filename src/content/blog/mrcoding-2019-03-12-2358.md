筆記：

今天筆記一下常用foreach的巡覽用法，相當實用，C# 尋覽雖然方便，但他初始化矩陣規則多一點，Java 要走多維陣列每一個元素麻煩一點，但相對來說就是彈性大一點，可在父子陣列中多做一些事情。

```csharp
using System;
					
public class Program
{
	public static void Main()
	{
		
		int[,] array2D = {{1,2},{3,4},{5,6},{7,8}}; //方正矩陣 [,]陣列
		int[][] array2D1 = new int[5][]; //[][]可以不規則
		array2D1[0] = new int[5]; //再針對不同父陣列產生子陣列空間
		foreach(int i in array2D){
			Console.WriteLine(i);
		}
	}
}
//輸出結果 1,2,3,4,5,6,7,8 
```

```java
class mingray {
  
  public static void main(String[] args) {
    
    int[][] array2D = {{1,2},{3,4},{5,6},{7,8},{7,8,9,10}}; //可以直接不規則初始化
    for(int[] i:array2D){ //父陣列i尋覽
       for(int ii:i){ //父陣列中的子陣列ii元素巡覽
            System.out.println(ii);
          }        
        }
  }
  
}
```
