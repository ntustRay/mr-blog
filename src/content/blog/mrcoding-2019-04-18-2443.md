## 字體效果

> *斜體字*  
>  **粗體字**  
>  ***斜粗體***  
>  ~~刪除線~~  
>  *斜體2*  
>  **粗體2**

```html
*斜體字*
**粗體字**
***斜體兼粗體***
~~刪除線~~
_斜體2_
__粗體2__
```

## 跳脫字元

\\加上可跳脫的標點符號（不是任意文字都需要或支援跳脫）

\\符號 \\符號

補充：表格與刪除線是 GitHub Flavored Markdown 等常見擴充，不是所有 Markdown 解析器都支援；顯示結果仍依平台實作而定。
