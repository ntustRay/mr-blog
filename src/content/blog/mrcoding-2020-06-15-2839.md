這是當時遇到 html2canvas 輸出自訂字型失效時的處理筆記；是否重現與套件版本、字型載入及跨網域資源有關。

當時嘗試把結果輸出到另一個既有的 canvas。`canvas` 選項只指定輸出畫布，不能保證修好字型問題；要擷取的 HTML 仍須有可計算的版面，不能把來源元素設成 `display: none`。先確認字型已載入，再進行擷取。

```javascript
document.fonts.ready.then(() => html2canvas(htmlElement, {
      scale: 2, // 輸出倍率；目前正式選項沒有 dpi
      logging: false,
      canvas: canvasElement, // 既有的輸出 canvas
    })).then(canvas => canvas.toDataURL('image/jpeg'));
```

若字型仍不正確，還要確認字型 URL、CORS 及套件版本；這個做法不是所有字型問題的通用解法。

堪誤參考：[官方文件](https://html2canvas.hertzen.com/configuration)、[官方文件](https://html.spec.whatwg.org/multipage/canvas.html)。
