再來就是測試程式碼是否在環境中可以成功執行

編譯器可把原始碼轉成目標程式；執行時仍需作業系統、必要函式庫或對應執行環境。IDE 是方便整合工具的選擇，並非執行程式的必要條件。

主題：

測試每個環境是否成可成功開始你程式碼人生

就是讓系統說出的Hello World！

只要能讓系統顯示出 Hello World就代表你們成功了第一步  

關鍵步驟：

1. 先寫主要執行區
2. 再執行區系統顯示出字串，內容為Hello World！

以下會用遊戲來解說

程式碼架構：

| 標頭區：  <br>  <br>例子：類似玩遊戲前說明書，看了就知道怎麼用怎麼玩。  <br>  <br>#include \<stdio.h\>// using System; // import os;   <br>這些將會在所有程式的最上頭，通常可以用來註解程式碼要用來幹嘛  <br>定義某些變數等  <br>引用其他人寫到的程式  <br>預編譯的時候省去一些煩人的 std::cout / System.Console.WriteLine("Hello World");   <br>前面的System 跟 std等等 |
| --- |
| 開始執行區：<br><br> <br><br>例子：玩遊戲時要，按開始遊戲，讓系統知道要開始玩了  <br>  <br>int main (void)／public static void main(String\[\] args)／python 不用  <br>此區目的是用來讓系統知道，裡面的{}裡的程式，當你按開始執行時，要進去裡面執行。 |
| 執行區：  <br>  <br>例子：進入遊戲了，準備開始打怪練功  <br>  <br>在{} 按開始執行就會執行的程式碼 (python不用{}) |
| 回傳區：<br><br> <br><br>例子：告知系統你是否成功進入遊戲，或登入遊戲  <br>  <br>在結尾的 }之前 有return 0; 通常0代表成功，當然也可以是其他數字或文字  <br>用來偵測會收取程式碼執行後的結果 |

下列是各種程式的例子

C++

```cpp
#include <iostream> //標頭區

using namespace std; //std 用了就不用前面加 std::cout

int main() { //開始執行區
  cout << "Hello World!"<< endl; //執行區
  return 0; //回傳區
} 
```

C

```cpp
#include <stdio.h> //C 必include 

int main(void) {
  printf("Hello World\n");
}
```

python 3.0以後

```python
print("Hello world")
```

Java

```java
class mingray {
  
  public static void main(String[] args) {
    
    System.out.println("Hello world");

  }
  
}
```

C#

```csharp
using System;
					
public class Program
{
	public static void Main()
	{
		Console.WriteLine("Hello World");
	}
}
```
