In IE CSS object fit this props is not surpported.

But background-size: contain can use it.

We just need to use background image in \<div\> instead of \<img\>.

```css
img{    
width: 100%;
height: 111px;
object-fit: contain; /* IE does not support object-fit. */
}

div{
width: 100%;
height: 111px;
background-image: url("image.jpg");
background-repeat: no-repeat;
background-position: center;
background-size: contain;
}
```

This is an Internet Explorer compatibility workaround. Internet Explorer 11 desktop support ended in 2022. A CSS background does not provide an image alt attribute; retain accessible text or an appropriate label when the image conveys information.
