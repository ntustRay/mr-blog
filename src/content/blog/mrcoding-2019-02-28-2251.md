在C++裡 struct class 幾乎完全一樣  
繼承、多形、建構子、界面都可以用

差在

|  | struct | class |
| --- | --- | --- |
| 預設屬性為 | public | private |
| 預設繼承 | public | private |
| 作為 template 的型別引數 | O | O |

`struct` 與 `class` 都可以定義類別模板，也都能作為型別引數。若這一列指的是 `template<class T>` 的型別參數宣告，這裡可以使用 `class` 或 `typename`，不能寫成 `template<struct T>`。
