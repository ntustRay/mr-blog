請先在自己的 WordPress 安裝 SyntaxHighlighter Evolved，就可以用短代碼呈現程式碼。以下短代碼放在 WordPress 文章內；此頁用程式碼區塊顯示語法。

```text
[code language="cpp"]
#include <iostream>
using namespace std;

int main() {
    cout << "Hello! World!\n";
    cout << "哈囉! C++!\n";
    return 0;
}
[/code]
```

以下為高亮第 5、6 行的例子！

```text
[sourcecode language="cpp" highlight="5,6"]
#include <iostream>
using namespace std;

int main() {
    cout << "Hello! World!\n";
    cout << "哈囉! C++!\n";
    return 0;
}
[/sourcecode]
```

勘誤參考：[SyntaxHighlighter Evolved](https://wordpress.org/plugins/syntaxhighlighter/)。
