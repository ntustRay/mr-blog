看網路補習影片，老師講話慢倒快睡著?   
半夜看謎片，老是把重要片段跳過?   
看謎片總是 看到不精采片段?   
只要在書籤上，加上這段程式碼，立刻幫影片加速

**目前此方法只適用*html5*** ***Video*標籤**

1. 新增書籤

![線上影片加速 - video *2 playbackRate，圖 1](../../assets/mrcoding/2020/08/image-2.webp)

2. 把網址改成程式碼

![線上影片加速 - video *2 playbackRate，圖 2](../../assets/mrcoding/2020/08/image-3.webp)

3. 測試:

https://www.w3schools.com/html/mov\_bbb.mp4

程式碼如下:

```javascript
javascript: (() => { const raw = prompt("請輸入影片速度（0.25～4）", "1.5"); if (raw === null) return; const rate = Number(raw); const video = document.querySelector("video"); if (video && Number.isFinite(rate) && rate >= 0.25 && rate <= 4) video.playbackRate = rate; })();
```

堪誤參考：[MDN 文件](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/playbackRate)。
