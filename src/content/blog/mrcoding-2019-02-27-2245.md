| Ctrl+1 | 快速修復任何已知問題 |
| --- | --- |
| Ctrl+Shift+F | 格式化程式碼 |
| Ctrl+Shift+M | 添加類的import導入 |
| Ctrl+Shift+O | 組織類的import導入（既有Ctrl+Shift+M的作用，又可以幫你去除沒用的導入，很有用） |

| Ctrl+/ | 註釋當前行,再按則取消註釋 |
| --- | --- |
| F3 | 找變數宣告處 |
| F6 | 逐步執行（Step Over） |
| F8 | 繼續執行到下一個中斷點（Resume） |
| Ctrl+R | 運行至行(超好用，可以節省好多的斷點) |

以上以 Windows 預設 Java 編輯器快捷鍵為例；`Ctrl+1` 提供目前游標位置可用的 Quick Fix，仍需依實際問題選擇修正。
