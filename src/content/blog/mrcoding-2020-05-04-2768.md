以下是常用的快捷鍵!  
供大家參考

| 1.自動排版 | Alt + Shift + F |
| --- | --- |
| 2.註解 | Ctrl + / |
| 3.取消註解 | Ctrl + / |
| 4.新增多重游標 | Alt + 滑鼠左鍵 |
| 5.查看定義 | F12 |
| 6.開啟終端機 | Ctrl + \` |
| 7.快速複製貼上 | Alt +Shift + 上下鍵 |

以上是 Windows 預設快捷鍵；macOS、Linux 或使用者自訂 keymap 可能不同。
