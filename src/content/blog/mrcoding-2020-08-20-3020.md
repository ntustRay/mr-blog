## 建立Cookies

下面的語法用來建立一個新的 cookie：

```javascript
document.cookie = "user_id=54088"; 
document.cookie = "lastBuy=nike_air_max"; 
console.log(document.cookie); 
// "user_id=54088; lastBuy=nike_air_max"
```

## 參數設定

- ***`path = path`***  
  設定 cookie 的路徑範圍，例如 `Path=/` 表示整站路徑；省略時由目前文件的目錄路徑推算。它不是阻止同源 JavaScript 存取的安全邊界。
- ***`domain = address`***  
  設定能讀取到此 cookie 的網域，例如從 `example.com` 設定 `Domain=example.com`，可供符合路徑的 `example.com` 與子網域使用；不能替不相關網域或 public suffix 設定 cookie。未指定時只屬於目前主機。
- ***`max-age = seconds`***  
  設定 cookie 的存活期限，單位為秒，例如 86400 就是一天後失效。
- ***`expires = date-in-GMTString-format`***  
  設定 cookie 的存活期限，值是一個 Date.toUTCString() 格式的時間字串。
- `Secure`（旗標，不是 `Secure=true`）  
   設定 cookie 只能於 https 連線中被傳送。

```javascript
//Example
document.cookie = "id=test0; Secure; Path=/; Domain=example.com"; 
document.cookie = "id=test1; Expires=Wed, 21 Oct 2015 07:28:00 GMT"
document.cookie = "id=test2; Max-Age=2592000"
```

```javascript
function parseCookie() {
    const cookieObj = Object.create(null);
    for (const part of document.cookie.split(';')) {
        const cookie = part.trim();
        const separator = cookie.indexOf('=');
        if (separator < 0) continue;
        cookieObj[cookie.slice(0, separator)] = cookie.slice(separator + 1);
    }
    return cookieObj;
}

function getCookieByName(name) {
    let value = parseCookie()[name];
    if (value !== undefined) 
        value = decodeURIComponent(value);
    return value;
}
```

我們就可以很方便的讀取 cookie，像是取得 username 的 cookie 只需要用 `getCookieByName('username')`。

#### **注意**

當我們在**設定的value**的時候，可以使用 **encodeURIComponent()**這個方法來儲存內容，可以讓特殊符號 $#@\*^!,這種轉換成URI形式，讓程式解析的時候比較不會出錯 。

```javascript
//Example
let content  = encodeURIComponent('http://example');
document.cookie = `id=${content}`;
// 實際內容: "id=http%3A%2F%2Fexample"
```

## 刪除Cookies

把目標 cookie 設為過期即可；刪除時的名稱、Path 與 Domain 必須與原 cookie 相同。以下未指定 Path／Domain 的範例，應在同一路徑與主機測試。

```javascript
//Example
document.cookie = `id=test1; max-age=86400`; //建立一個新的
document.cookie = `id=test1; max-age=0`;  //讓他立刻到期，用expires也是一樣作法
```

## 範例區:

#### 新增Cookies

```html
<input placeholder="請輸入key值" id="cookiesKey">
```

```html
<input placeholder="請輸入value值" id="cookiesValue">
```

```html
<button onclick="addCookies()">submit</button>
```

```html
<script>
 function addCookies() {
   let key = document.getElementById('cookiesKey').value;
   let value = document.getElementById('cookiesValue').value;
   document.cookie = `${key}=${encodeURIComponent(value)}; max-age=999999`; 
   console.log(`新增key: ${key}, value: ${value}`);
   alert(`新增Cookies: \'${key}=${value}\'`);
 }
</script>
```


`document.cookie` 只能存取未標記 `HttpOnly` 且符合目前範圍的 cookie。用 `encodeURIComponent` 寫入值後才用 `decodeURIComponent` 讀回；外部來源的值若不是合法百分比編碼，解碼可能拋出例外，正式程式需處理。
