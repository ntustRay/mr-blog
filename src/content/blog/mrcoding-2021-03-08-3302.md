If you tap the last dots and swipe it to the right edge and swipe left one page. The dots will disappear.

The problem is the targetSlide is wrong.

```jsx
  onSliderEdge = () => {
    const {slidesToShow} = sliderSettings
    const lastCount = this.slider.innerSlider.state.slideCount - slidesToShow
    const lastTarget = this.slider.innerSlider.state.targetSlide
    if (lastCount === this.slider.innerSlider.state.currentSlide)
      this.slider.slickGoTo(lastTarget);
  }      

<Slider ref={r => this.slider = r} {...sliderSettings} onEdge={this.onSliderEdge}>
   {list.map(value => value)}
</Slider>
```

We force to update the targetSlide after tapping the last dot and swipe it on edge.

> Version note / 版本註記：這是 2021 年特定設定下的 workaround，讀取 `innerSlider.state` 屬套件內部實作，沒有公開 API 的相容性保證。`slideCount - slidesToShow` 也假設沒有 center／variable-width 等特殊模式；responsive 設定可能改變有效值。請依使用的版本與設定重現確認，不能當作所有輪播通用修正。
