筆記：

兩者都是類似語法很相近，但array用法有點差

而array java的是

```java
int[][] multi = new int[5][10];

int[][] multi = new int[5][];
multi[0] = new int[10];
multi[1] = new int[9];
multi[2] = new int[8];
multi[3] = new int[7];
multi[4] = new int[6];

int[][] multi = new int[][]{{0,1},{1,1}};
```

而C# 一次命名要多維陣列則要用逗號\[,\]

```csharp
int[,] multi = new int[5,10];

//而C#也可以用[][]的用法，但子陣列不能直接宣告大小

int[][] multi = new int[5][];

multi[0] = new int[10];
multi[1] = new int[9];
```

以上各段 `multi` 宣告是不同的替代範例，不能直接一起貼到同一個作用域。Java 的 `[][]` 與 C# 的 `[][]` 都是陣列的陣列；C# 的 `[,]` 則是矩形多維陣列。
