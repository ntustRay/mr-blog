今天來筆記一下unity兩個物體的角度  
使用 Unity 的 `Vector3.Angle(向量, 向量)` 取得夾角（0–180 度）。這段程式算的是物體 b 的正前方向，與 b 指向 a 的方向之間的夾角，不是兩個物體旋轉姿態之差。

```csharp
using UnityEngine;

public class AngleExample : MonoBehaviour
{
   		public float getAngle2 (Transform a, Transform b) 
		{
			Vector3 targetDir = a.position - b.position;
        float angle = Vector3.Angle(targetDir, b.forward);

        if (angle < 5.0f)
            print("close");
		return angle;
		}
}

//修改自來源:https://docs.unity3d.com/ScriptReference/Vector3.Angle.html
```
