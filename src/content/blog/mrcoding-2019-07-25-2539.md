OpenCV的影像顏色處理排序為BGR  
畫面為左上角為原點，如下圖所示

(0,0) → (1,0)  
 ↓ ↓  
(0,1) → (1,1)

並且需要安裝三個套件

1. **Pillow（現行維護的 PIL 分支，匯入名稱仍為 PIL）**
2. **opencv-python**
3. **numpy**

即可使用以下程式碼進行螢幕錄影

備註：錄影時間過短，或關掉時沒運行到video.release()可能造成影片的一些播放問題  
並且傳入 `VideoWriter.write()` 的每一幀尺寸，必須與建立 `VideoWriter` 時指定的尺寸相同；不只是大於或等於即可。  
預覽視窗若落在擷取範圍內，會出現畫面套疊的效果。可把預覽視窗移到擷取範圍外、改擷取區域，或使用第二個螢幕；不是一定需要雙螢幕。  
而[https://stackoverflow.com/questions/49095446/python-opencv-remove-title-bar-toolbar-and-status-bar|](https://stackoverflow.com/questions/49095446/python-opencv-remove-title-bar-toolbar-and-status-bar)  
這篇的效果我放進去也還是會造成預覽螢幕重疊的效果，希望之後能改善。

```python
from PIL import ImageGrab
import numpy as np
import cv2

image = ImageGrab.grab()#取的當前主螢幕
width = image.size[0]
height = image.size[1]

print("width:", width, "height:", height)
print("image mode:",image.mode)

bbox = (460, 175, 1400, 850) # (x1, y1, x2, y2)，請依螢幕大小調整
frame_size = (bbox[2] - bbox[0], bbox[3] - bbox[1])
fourcc = cv2.VideoWriter_fourcc(*'XVID')
video = cv2.VideoWriter('test.avi', fourcc, 30, frame_size)
if not video.isOpened():
    raise RuntimeError('無法開啟 VideoWriter，請確認輸出路徑及編碼器')

try:
    while True:
        img_rgb = ImageGrab.grab(bbox=bbox).convert('RGB')
        img_bgr = cv2.cvtColor(np.array(img_rgb), cv2.COLOR_RGB2BGR)
        video.write(img_bgr)
        cv2.imshow('Preview', img_bgr) # waitKey 需有啟用中的 HighGUI 視窗
        if cv2.waitKey(1) & 0xFF == ord('q'): # 在預覽視窗按 q 結束
            break
finally:
    video.release()
    cv2.destroyAllWindows()
```

注意：`30` 是輸出影片的播放幀率，這個簡易迴圈不保證實際擷取速度也正好每秒 30 幀；錄影較慢時，輸出影片的播放時間可能和實際經過時間不同。
