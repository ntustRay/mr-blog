筆記：  
InputStream／OutputStream 讀寫 byte（每個 byte 為 8 位元）  
Reader/Writer 更適合讀字串字元 都是讀char或string

可用 `InputStreamReader` 將 byte 輸入依指定編碼解碼成字元，或用 `OutputStreamWriter` 將字元依指定編碼寫入 byte 輸出串流。Java 標準庫沒有對稱的通用 Reader→InputStream 轉接類別；若需要轉換，必須明確處理字元編碼。

底層分別為 FileInput/OutputStream 及 FileReader／FileWriter   
而Buffer等級為  
BufferedInput/OutputStream 及 BufferedReader／BufferedWriter

```java
package iotest;

import java.io.*;

public class StreamVSReader {

	public static void main(String[] args) throws Exception {
		
			// InputStreamReader：byte 輸入轉字元讀取
            // OutputStreamWriter：字元寫入轉 byte 輸出
		
			// 例如 new InputStreamReader(new FileInputStream(path), "UTF-8")；編碼須和檔案一致
			
			//Stream類 接收bytes，binary 
			FileInputStream reader = new FileInputStream("./newfolder/file2");
			BufferedInputStream bs = new BufferedInputStream(reader);
			int temp;
			while ((temp = bs.read()) != -1) { // 讀到沒資料的時候 read()此方法會return -1
				System.out.print((char) temp);
			}
			// Reader 類依字元編碼解碼；不能因為是中文就省略檔案編碼的確認
			BufferedReader input = new BufferedReader( new InputStreamReader(new FileInputStream("./newfolder/file2"), "UTF-8")); //讀中文 
			String str;
			while((str= input.readLine())!=null) {
				System.out.println(str);
							
			}
            bs.close();
            input.close();
	}
		

}
```
