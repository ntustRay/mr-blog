How to detect when an image has loaded and decoded? `load`、解碼與實際呈現在螢幕上是不同階段。

1. React 的圖片載入事件

```jsx
function loaded(event) {
  console.log('loaded', event.currentTarget.naturalWidth);
}

<img src="/example.png" onLoad={loaded} alt="範例" />
```

React 要用 `onLoad={loaded}` 傳入函式，不能用 `onload={loaded()}`，否則會在 render 時直接呼叫。

2. 先等待解碼，再安排畫面更新

```javascript
async function showImage(src, container) {
  const image = new Image();
  image.alt = "範例";
  image.src = src;
  await image.decode(); // 失敗會拒絕 Promise，由呼叫端處理
  container.appendChild(image);
  requestAnimationFrame(() => {
    requestAnimationFrame(() => {
      console.log('已經過後續畫面更新的排程機會');
    });
  });
}
```

`decode()` 用來等待圖片解碼完成；`requestAnimationFrame` 在重繪之前執行，連續兩次常用來跨過一次更新機會，但不是「100% 已顯示在螢幕上」的保證。背景分頁可能暫停回呼，也沒有通用 API 可保證某張圖已實際送到螢幕。

堪誤參考：[MDN 文件](https://developer.mozilla.org/en-US/docs/Web/API/HTMLImageElement/decode)、[MDN 文件](https://developer.mozilla.org/en-US/docs/Web/API/Window/requestAnimationFrame)。
