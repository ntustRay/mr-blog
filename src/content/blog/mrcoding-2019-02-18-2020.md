筆記一下：

class 宣告定義類別；使用 `new user("名字")` 才會建立物件實體，並呼叫對應的建構子。

建構子不是另一個類別；它的名稱與類別相同、沒有回傳型別，用來初始化新物件。以下兩個 public 類別請分別存成 user.java 與 LOLstart.java，並放在同一個 package。

```java
public class user {
	
   static int how_many_man; //全域變數

	String username;
	int power,smart,speed;
	
	user(String name){
		username = name;
		power =87;
		how_many_man++;
	}		
	 void be_strong() {
		power ++;
	}
	 void be_fast(){
		speed++;
	}
	 int how_strong() {
		return power;
	}
	 int how_fast() {
		return speed;
	}
}
```

```java
public class LOLstart{

	public static void main(String[] args) {
		
		
		
		user newStrongMan = new user("動主BO");	
		user twoStrongMan = new user("AAAAA");
		user threeStrongMan = new user("還敢下來阿冰鳥");
		
		System.out.println("新人的數量:"+ user.how_many_man); 
		
		newStrongMan.be_strong();
		System.out.println("新人的力量:"+ newStrongMan.power); 
		System.out.println("新人的名字:"+ threeStrongMan.username); 

		
	
	}
}
```
