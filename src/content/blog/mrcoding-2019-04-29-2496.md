筆記：

建構子不會被子類別繼承。子類別建構子的參數數量及型別不必包含父類別的全部參數；只要能呼叫某個可存取的父類別建構子即可，也可以傳入常數或計算結果。

建立子類別物件時必須完成父類別初始化。以下範例的父類別沒有無參數建構子，所以使用 `super(參數)`；若有可存取的無參數建構子，編譯器可以隱含呼叫 `super()`。也能用 `this(...)` 先委派同類別的其他建構子，再由該建構子呼叫父類別。

```java
class grandfather {
	grandfather(int a) {

	}
}

class father extends grandfather {

	father(int a, String name) {
		super(a);
	}

}

class son extends father {

	son(int money, String name, double rate) {
		super(money, name);
	}

}
```
