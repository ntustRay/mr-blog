若完成上次 的教學，改了code，就重複上次的步驟就可以囉

[相關文章](../mrcoding-2019-10-23-2613/)

開啟cmd 打上

cd your-app-name

npm run deploy

git add .

git commit -m "Your awesome message"

git push origin HEAD

等待 GitHub Pages 部署完成後，開啟 `https://youraccount.github.io/your-app-name` 查看成果；部署時間不一定是 1～2 分鐘。

這篇沿用舊版 Create React App + gh-pages 流程，前提是已設定 `predeploy`、`deploy` 以及 Pages 的 `gh-pages` 發布來源。Create React App 現已棄用於新專案；既有專案仍可依自己的設定部署。

勘誤核對來源：[1](https://react.dev/blog/2025/02/14/sunsetting-create-react-app)、[2](https://create-react-app.dev/docs/deployment/#github-pages)。
