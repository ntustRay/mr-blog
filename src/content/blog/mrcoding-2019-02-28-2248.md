筆記：

- Runtime Exception

屬於 unchecked exception，編譯器不強制要求捕捉或宣告；例外仍是在執行時拋出。

- Checked Exception

編譯器會要求捕捉可能發生的 checked exception，或在方法上以 `throws` 宣告；不是例外在編譯時就已經發生。

try{抓出現例外的程式碼}  
catch(例外類型宣告 例外變數名稱)  
{若出現例外執行這裡的程式碼}  
finally{離開 try/catch 時通常都會執行這段程式碼；若 JVM 被終止（如 System.exit）則不保證執行}

```java
package test;

public class TryCatchFinally {

	public static void main(String[] args) {
		// TODO Auto-generated method stub

		int a = 0, b = 10; 

		try {//runtime Exception 執行程式碼才知道有錯，編譯會過
			System.out.println("b/a = " + b / a); // 整數除以 0 會拋出 ArithmeticException；浮點數除以 0 的規則不同
		} catch (ArithmeticException ae) {
			System.out.println("第1個例外");
			System.out.println(ae.toString()); // 印出錯誤內容
		} finally {
			System.out.println("一定會執行finally");

		}

		innerclass inclass = new innerclass();
		// inclass.MorethanfiveWillError(90); //未捕捉或宣告 checked exception 會編譯錯，僅改傳入值仍無法解除此要求
		try {
			inclass.MorethanfiveWillError(90);
		} catch (Exception SE) {
			System.out.println(SE.toString());
		}

	}

}

class innerclass {
	void MorethanfiveWillError(int index) throws Exception {//這個方法要說 會丟出例外
		if (index > 5) {
			throw new Exception("太神拉不能超過5"); // checked exception：呼叫端必須捕捉或宣告，實際仍在執行時拋出
		}
	}
}
```
