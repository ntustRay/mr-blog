將使用 sort方法，為Array的方法，  
若 object需要使用 則需要Object方法轉成陣列

| 小到大 | sort((a,b) =\> a - b) |
| --- | --- |
| 大到小 | sort((a,b) =\> b - a) |

```javascript
let array = [4, 5, 3, 1, 2]
let object = {'小明': {'分數': 95}, '小夫': {'分數': 87}, '胖虎': {'分數': 69}}

let newArray = array.sort((a, b) => a - b)
// [1,2,3,4,5]
let sortedEntries = Object.entries(object).sort((a, b) => a[1]['分數'] - b[1]['分數']);
// [ ["胖虎", {分數: 69}], ["小夫", {分數: 87}], ["小明", {分數: 95}] ]
let sortedValues = Object.values(object).sort((a, b) => a['分數'] - b['分數']);
// [ {分數: 69} {分數: 87} {分數: 95} ]
let sortedKeys = Object.keys(object).sort((a, b) => object[a]['分數'] - object[b]['分數']);
// [ "胖虎", "小夫", "小明" ]
```

`sort()` 會直接修改原陣列，並回傳同一個陣列；若要保留 `array` 原順序，可改用 `[...array].sort(...)`。
