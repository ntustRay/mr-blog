Ref 可以取得 React 所管理的實際 DOM 節點；它不是另一種 DOM，也沒有「取得記憶位置所以比較耗能」這個一般規則。

掛載時 React 會設定 ref，class 的 `componentDidMount` 執行時就可使用；移除節點時會清除 ref。callback ref 可能在更新時被清除再設定，特別是每次 render 都建立新的 inline callback，因此不是整個生命週期只觸發兩次。

兩種寫法:

```jsx
class ObjectRefExample extends React.Component {
  constructor(props) {
    super(props);
    this.textInputRef = React.createRef();
  }
  render() {
    return <input type="text" ref={this.textInputRef} />;
  }
}
```

```javascript
	<input type="text" ref={(r) => (this.numberInputRef = r)} />
```

第一種是 class component 常見的 object ref 寫法，callback ref 則適合需要自訂節點設定／清理的情況。function component 通常使用 `useRef`；並不是所有情境都必須選第一種。詳見 [React createRef 文件](https://react.dev/reference/react/createRef)。

以下為Demo程式碼

```javascript
class App extends React.Component {
  constructor(props) {
    super(props);
    this.textInputRef = React.createRef();
  }

  handleSubmit = (event) => {
    alert(
      "Name: " +
        this.textInputRef.current.value + //用 createRef的方法要用current
        " id :" + 
        this.numberInputRef.value // 這個不用
    );
    event.preventDefault();
  };

  render() {
    return (
      <form onSubmit={this.handleSubmit}>
        <label>
          Name:
          <input type="text" ref={this.textInputRef} />
        </label>
        <label>
          id :
          <input type="text" ref={(r) => (this.numberInputRef = r)} />{/*r 是實際 DOM 節點；清除時會收到 null*/}
        </label>
        <input type="submit" value="Submit" />
      </form>
    );
  }
}
```
