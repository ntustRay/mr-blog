結合上篇 notification 的功能，來製作健康提醒器。這次使用 React Hook 來完成。

```javascript
setTimeout(notify, 3600000); // 第一個參數放方法，第二個參數是毫秒
```

權限請求要從按鈕點按開始；計時器則使用自己的 ref 保存，不能用 `window.stop`，因為那是瀏覽器內建的「停止載入」函式。

```javascript
import React, { useEffect, useRef } from "react";
import "./styles.css";
import walkIcon from "./walk.jpg";

const getTime = () => new Date().toLocaleTimeString("zh-TW", {
  hour: "numeric", minute: "2-digit", hour12: true
});

const notify = (firstTime = false) => {
  if (Notification.permission !== "granted") return;
  new Notification("健康提醒", {
    body: (firstTime ? "開始提醒" : "起來動一動囉!") + `\n現在時刻:${getTime()}`,
    icon: walkIcon
  });
};

export default function App() {
  const timerRef = useRef(null);
  const mountedRef = useRef(true);

  useEffect(() => {
    mountedRef.current = true;
    return () => {
      mountedRef.current = false;
      clearTimeout(timerRef.current);
    };
  }, []);

  const startReminders = async () => {
    if (!("Notification" in window)) return;
    let permission = Notification.permission;
    if (permission === "default") {
      permission = await Notification.requestPermission();
    }
    if (permission !== "granted" || !mountedRef.current) return;
    clearTimeout(timerRef.current);
    notify(true);
    const tick = () => {
      notify();
      timerRef.current = setTimeout(tick, 3600000);
    };
    timerRef.current = setTimeout(tick, 3600000);
  };

  return (
    <div className="App">
      <h1>健康提醒器</h1>
      <h2>每個小時提醒起來動一動，請按允許通知</h2>
      <button onClick={startReminders}>開始提醒</button>
    </div>
  );
}
```

這是 HTTPS／localhost 上的桌面網頁範例。背景分頁的計時器可能被節流，關閉網頁也會停止，不能保證整點或關頁後仍發出通知。
