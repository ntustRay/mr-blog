本次倒數已經出現提醒時，最小化或按視窗的 X，倒數都會繼續。要停止它，請按「取消本次關機」。Windows 若有每週固定排程，取消這一回之後，下一次仍照原時間啟動。要停止往後的排程，回主視窗按「停用每週排程」。

## 多個入口需要有看得見的結果

| 操作 | 倒數和排程會怎麼變 |
| --- | --- |
| 提醒出現前關閉單次模式的主視窗 | 該次倒數取消。 |
| 提醒進行時最小化或按 X | 倒數繼續。最小化後可以從桌面工作列或 Dock 還原，取決於桌面環境。 |
| 提醒內延後 | 本次預定時間往後移，固定的每週規則照舊。 |
| 提醒內取消 | 停止本次倒數。 |
| 在 Windows 主視窗停用每週排程 | 移除未來的觸發規則，已經出現的提醒要在該視窗內取消。 |

最後五分鐘讓使用者有時間反應，但啟動通知也可能被排程延遲。這版到期時會檢查提醒已進入顯示狀態至少 30 秒。顯示太晚時，程式取消這一回並留下原因。設計上接受一次沒執行，避免使用者看到視窗就立刻失去操作機會。

## 每週排程適合使用者已登入的 Windows 桌面

Windows 每週模式由工作排程器以目前使用者身分啟動，需要當時已登入而且電腦保持清醒。它不喚醒電腦，也不補跑錯過的觸發。單次模式只需在要用時開啟應用程式，但倒數依賴該程式保持執行，跨睡眠或休眠的時序也要各自測。

交接時可以留平台、版本、模擬／真實模式、原定時間和最後結果。若「提醒沒有出現」，先查排程有沒有啟動，再分別看程式視窗與 Windows 橫幅。若「取消後隔天還有提醒」，查的是每週規則是否仍生效。前篇在 Linux 圖形環境實際驗了啟動、延後和取消。桌面工作列還原、Windows 橫幅、macOS 桌面操作和真正的關機執行都需要各平台的實機驗證。
