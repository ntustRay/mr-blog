這是舊版 React Router 與 Redux 整合的排錯筆記。`react-router-redux` 4.x 的範例搭配 React Router 2／3；React Router 4 已不再匯出原本的 `browserHistory`。混用版本時，把 `undefined` 傳入 `syncHistoryWithStore`，就可能出現讀不到 `listen` 的錯誤。

舊專案應先核對相容版本，以及實際傳入的 history 與 store：

```javascript
// 適用舊版 react-router 3.x + react-router-redux 4.x
import { syncHistoryWithStore } from "react-router-redux";
import { browserHistory } from "react-router";
const history = syncHistoryWithStore(browserHistory, store);
```

不要直接改成 `import { createHistory } from 'history'` 當作通用修法；`history` 不同主要版本的匯出與 API 也不相同。自行建立 history 時，Router 與同步工具必須共用同一個相容實例。

> `react-router-redux` 專案已棄用並於 2018 年封存，以上保留為舊專案紀錄。新專案不應照此建立路由整合。
