`ß` is a German lowercase letter. JavaScript's default Unicode uppercase mapping converts it to `SS`, so `'schließen'.toUpperCase()` returns `SCHLIESSEN`. This is expected behavior, not a JavaScript bug.

The capital letter `ẞ` (U+1E9E) also exists, but it is not the default uppercase mapping for `ß`. If a product requires `ẞ`, apply that specific typography rule explicitly rather than assuming uppercase conversion preserves string length.
