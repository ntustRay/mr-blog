筆記也分享一下，偶爾會用到。

```csharp
using System.Diagnostics; //Process 會用到


       private static void StartEXE()
        {

            Process p = Process.Start(@"D:\爬蟲.exe");
    
            p.WaitForExit();//等待爬完蟲結束才開始執行下一行程式碼


        }
```
