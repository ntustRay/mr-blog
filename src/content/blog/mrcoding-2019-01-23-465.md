------------------------------以下開始申請免費Domain------------------------

1.Google freenom 找到他並且輸入你要的網址，檢查可用性

![7步驟github架站+12步驟申請免費Domain(連結修正)，圖 8](../../assets/mrcoding/2019/01/image-71.webp)

2. 選擇一個免費你要的網址

![7步驟github架站+12步驟申請免費Domain(連結修正)，圖 9](../../assets/mrcoding/2019/01/image-72.webp)

3. 超過12個月要付費，我都剛好選12個月

![7步驟github架站+12步驟申請免費Domain(連結修正)，圖 10](../../assets/mrcoding/2019/01/image-73.webp)

4. 申請好後會較你付款申請帳號，好了後右上角選擇Services選My Domains  
且選擇Manage Domain這個選項

![7步驟github架站+12步驟申請免費Domain(連結修正)，圖 11](../../assets/mrcoding/2019/01/image-74.webp)

5. 選擇管理你的DNS

![7步驟github架站+12步驟申請免費Domain(連結修正)，圖 12](../../assets/mrcoding/2019/01/image-76.webp)

6. 依 GitHub Pages 官方文件設定 DNS；Pages 的 A 記錄 IP 是共用的，並非每個帳號都有獨有 IP。

![7步驟github架站+12步驟申請免費Domain(連結修正)，圖 13](../../assets/mrcoding/2019/01/image-75.webp)

7. 看完之後去freenom設定

![7步驟github架站+12步驟申請免費Domain(連結修正)，圖 14](../../assets/mrcoding/2019/01/image-77.webp)

8. 根網域的 A 記錄指向官方列出的 GitHub Pages IP；`www` 子網域的 CNAME 建議直接指向 `<你的帳號>.github.io`，不要加 `https://` 或專案路徑。先在 Pages 綁定自訂網域，再新增 DNS 記錄。

![7步驟github架站+12步驟申請免費Domain(連結修正)，圖 15](../../assets/mrcoding/2019/01/image-79.webp)

這邊的DNS IP我複製錯了哈哈哈哈，我很87，錯誤示範

9. 再來回來剛剛的專案，選擇code建立新檔案

![7步驟github架站+12步驟申請免費Domain(連結修正)，圖 16](../../assets/mrcoding/2019/01/image-80.webp)

10. 以分支發布時，來源目錄中的檔名為 `CNAME`，內容是自訂網域，不含協定；使用自訂 GitHub Actions 工作流程時不需要此檔。

![7步驟github架站+12步驟申請免費Domain(連結修正)，圖 17](../../assets/mrcoding/2019/01/image-81.webp)

11. 建立好之後，回來settings 在custom domain輸入你要的網址且 Save

![7步驟github架站+12步驟申請免費Domain(連結修正)，圖 18](../../assets/mrcoding/2019/01/image-82.webp)

12. 成功囉!! 如果沒成功導向你的免費網址，github會跟你說喔!

![7步驟github架站+12步驟申請免費Domain(連結修正)，圖 19](../../assets/mrcoding/2019/01/image-83.webp)

是不是很簡單呢? 建立一個網站+申請Domain不用10分鐘喔
