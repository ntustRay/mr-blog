**物件導向程式**（Object-oriented programming，縮寫：OOP）

程式的運作就是由不同物件來運行的  
以這篇的 C# 範例來說，物件是依類別建立的實體。  
類別概念：  
職業類別：初心者 物件：一個玩家阿明一進遊戲是初心者  
所有初心者類別  
屬性有： 力量、敏捷、智慧  
招是有：烙跑、打怪

物件導向的三大特性:

1. 封裝:(Encapsulation)：把寫好的東西包起來，把程式碼包起來，玩家只能按遊戲介面。
2. 繼承(Inheritance)：玩家轉職不同職業，如超強弓箭手會繼承弓箭手的技能。
3. 多型(Polymorphism)：同樣普通攻擊，不同的職業參考的數據不同，弓箭手原本吃重敏捷，轉職成超強弓箭手也會吃到智慧加成( 覆寫普通攻擊 )。索隆一刀流、二刀流、三刀流同樣的武器，會有不同的輸出( 多載 )

封裝：  
顧名思義就是把東西封裝起來，你只能用他給你的遊戲介面來進行攻擊、施放技能，實際上你不知道他裡面的程式碼怎麼運作。

```csharp
class 初心者
{
    private void 揮動武器() {} //在遊戲介面沒有的選項
    
    public void 攻擊(){ 揮動武器(); } //攻擊就是拿武器K敵人
}

class 玩家
{
    初心者 馬小九 = new 初心者(); //一個新玩家
    public void 按下攻擊() { 馬小九.攻擊(); } //只能呼叫公開攻擊方法，無法從此類別呼叫 private 的揮動武器。
}
```

繼承：  
轉職成戰士，還是會有可繼承的技能跟屬性。以下兩段用「屬性／方法」描述概念，是偽碼，不是可直接編譯的 C#。

```csharp
class 初心者
{
        屬性: 力量,敏捷,智慧,血量;
        方法: 攻擊();        
}

//繼承初心者所有屬性

class 戰士:初心者 //轉職成功可以放技能會消耗MP
{
        屬性: 魔力;
        方法: 雙重攻擊();
}
```

多型：  
覆寫是子類別提供父類別方法的不同實作，C# 要搭配父類別的 virtual／abstract 與子類別的 override。多載則是同名方法使用不同的參數型別或數量，不能只靠傳入數值不同來區分。

```csharp
class 初心者
{
        屬性: 力量,敏捷,智慧,血量;
        方法: 攻擊(){力量*0.5};        
}
class 戰士:初心者 
{
       攻擊(){力量*1.5}; // 覆寫 攻擊計算方式不一樣了

       雙重攻擊(一把武器); //多載 多把武器傷害更高
       {傷害*1+力量*1} 
       雙重攻擊(兩把武器);
       {傷害*2+力量*1+敏捷*1} 
}
```
