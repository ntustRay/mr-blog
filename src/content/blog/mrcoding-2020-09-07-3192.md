這篇比較的是 2020 年的整合方式：當時 `react-router-redux` 4.0.8 已停止維護；`connected-react-router` 6.8.0 則提供 React Router 4／5 與 Redux 的整合。

`react-router-redux` 後來已封存；`connected-react-router` 也不能因為套件版本叫 6.x，就當成支援 React Router 6 或之後版本。使用前要核對 React、Redux、React Router 與 history 的相容版本。

因此，本文當年的推薦僅適用相符版本的舊專案。新專案應依目前路由工具的文件選擇整合方式，不宜直接沿用「與最新版完美契合」的結論。

堪誤參考：[官方文件](https://github.com/reactjs/react-router-redux)、[官方文件](https://github.com/supasate/connected-react-router)。
