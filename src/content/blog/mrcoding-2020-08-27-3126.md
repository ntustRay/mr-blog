因為新版的語法不支援了

The new FB API does not support "share\_open\_graph", only the following syntax is supported.

現在只支援 :

| `app_id` |
| --- |
| `redirect_uri` |
| `display` |
| `from` |
| `to` |
| `link` |
| `source` |
| `ref` |

```javascript
    FB.ui({
            method: 'feed',
            name: 'Come Listen to this Song', //unsupported
            link: url_base + '/listen',
            picture: self._song.share_img,  //unsupported
            caption: 'mywebsite.com',  //unsupported
            description: msg,  //unsupported
            message: msg  //unsupported
        }, function(response){});
```

```javascript
FB.ui({
    method: "share_open_graph", //unsupported
    action_type: "og.shares", //unsupported
    action_properties: JSON.stringify({ //unsupported
      object: { //unsupported //unsupported
        "og:url": FBLink, //unsupported
        "og:title": FBTitle, //unsupported
        "og:description": FBDesc, //unsupported
        "og:image": FBPic //unsupported
      }
    })
  },function (response) {});
```

補充：上面的程式碼是當時失效參數的紀錄，不是可直接使用的新範例。分享圖片通常應由被分享頁面的 Open Graph 中繼資料提供，例如 `<meta property="og:image" content="https://example.com/share.jpg">`，並檢查圖片可公開存取、網址及分享快取。不同 Dialog／API 版本的參數不同，不能把上表當作所有版本通用的完整清單；請依 Meta 官方文件核對。

堪誤參考：[官方文件](https://developers.facebook.com/docs/sharing/webmasters/)、[官方文件](https://developers.facebook.com/docs/sharing/reference/share-dialog/)。
