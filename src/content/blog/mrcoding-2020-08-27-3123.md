Hook 可以讓函式元件使用 state 與其他 React 功能，也適用複雜元件；是否使用 class 不由元件複雜度決定。

`useEffect` 用來在提交畫面後同步外部系統，並不是 class 生命週期的一對一替換。省略依賴陣列時，每次提交後都會執行；`[]` 通常只在掛載後執行；`[name]` 則在第一次掛載及 `name` 改變後執行。cleanup 會在下次 Effect 重跑之前及卸載時執行，不只在卸載時。

`componentDidUpdate` 是更新提交後的回呼，不是它觸發 render；class 也可能透過 `shouldComponentUpdate` 等方式跳過更新。開發環境 Strict Mode 可能額外執行 Effect 的 setup／cleanup。

```javascript
  useEffect(() => { 
    // 掛載後 setup；不是所有 class 生命週期的直接替換
  }, []);

  useEffect(() => {
    // 第一次掛載，以及 name 改變後的 setup
    return () => {
    // 下次 setup 前，以及卸載時 cleanup
    };
  }, [name]); //if( name!= previousState) 
```

原本

```javascript
class App extends React.Component {
  constructor(props) {
    super(props);
    this.state = {
      name: "湯姆貓"
    };
    this.action = null;
  }

  componentDidMount() {
    this.action = "準備抓貓";
  }

  componentDidUpdate() {
    this.action = "抓貓";
  }

  componentWillUnmount() {
    this.action = "休息";
  }

  render() {
    return (
      <div>
        {this.state.name}
        <button onClick={() => this.setState({ name: "壞貓咪" })}>按我</button>
        <button onClick={() => alert("狀態: " + this.action)}>狀態</button>
      </div>
    );
  }
}
```

Hook 寫法（這兩個 Effect 都會在掛載時執行，因此最後 action 為「抓貓」；合體範例則為「跑啊」。ref 用來保留非畫面狀態，並不觸發重新渲染）

```javascript
const App = () => {
  const [name, setName] = useState("湯姆貓");
  const action = useRef(null);

  useEffect(() => {
    action.current = "準備抓貓";
  }, []);

  useEffect(() => {
    action.current = "抓貓";
    return () => {
      action.current = "休息";
    };
  });

  return (
    <div>
      {name}
      <button onClick={() => setName("臭老鼠")}>按我</button>
      <button onClick={() => alert("狀態: " + action.current)}>狀態</button> 
    </div>
  );
};

ReactDOM.render(<App />, document.getElementById("app"));
```

合體

```javascript
import React, { useState, useEffect, useRef } from "react";
import ReactDOM from "react-dom";

class App extends React.Component {
  constructor(props) {
    super(props);
    this.state = {
      name: "湯姆貓"
    };
    this.action = null;
  }

  componentDidMount() {
    console.log("準備抓貓");
    this.action = "準備抓貓";
  }

  componentDidUpdate() {
    console.log("抓貓");
    this.action = "抓貓";
  }

  componentWillUnmount() {
    console.log("休息");
    this.action = "休息";
  }

  render() {
    return (
      <div>
        {this.state.name}
        <button onClick={() => this.setState({ name: "壞貓咪" })}>按我</button>
        <button onClick={() => alert("狀態: " + this.action)}>狀態</button>
        <UseStateHook />
      </div>
    );
  }
}

const UseStateHook = () => {
  const [name, setName] = useState("傑立鼠");
  const action = useRef(null);

  useEffect(() => {
    console.log("準備躲貓");
    action.current = "準備躲貓";
  }, []);

  useEffect(() => {
    console.log("跑啊");
    action.current = "跑啊";
    return () => {
      console.log("躲起來");
      action.current = "躲起來";
    };
  });

  return (
    <div>
      {name}
      <button onClick={() => setName("臭老鼠")}>按我</button>
      <button onClick={() => alert("狀態: " + action.current)}>狀態</button> 
    </div>
  );
};

ReactDOM.render(<App />, document.getElementById("app"));
```
