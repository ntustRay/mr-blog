今天教大家，如何輕鬆簡單地寫出桌面通知，讓 Chrome 跳通知出來。

1. 確認瀏覽器支援 `Notification`，並在 HTTPS（或 localhost）執行。
2. 由使用者點按按鈕時請求權限。
3. 只有結果為 `granted` 才建立通知；`default` 或 `denied` 都不顯示。

```html
<button onclick="notify()">點我測試</button>
```

```html
<script>
async function notify() {
  if (!("Notification" in window)) return;
  let permission = Notification.permission;
  if (permission === "default") {
    permission = await Notification.requestPermission();
  }
  if (permission !== "granted") return;

  new Notification("通知標題", {
    body: "訊息內容",
    icon: "/image.jpg" // 換成網站可讀取的圖片
  });
}
</script>
```

這個範例是桌面瀏覽器的頁面通知；手機瀏覽器可能需要 Service Worker 的 `showNotification()`，不能把 `new Notification()` 視為所有裝置通用的寫法。

堪誤參考：[MDN 文件](https://developer.mozilla.org/en-US/docs/Web/API/Notification/requestPermission_static)、[MDN 文件](https://developer.mozilla.org/en-US/docs/Web/API/Notification/Notification)。
