--Deploy on github pages  

npx create-react-app app-name  

cd app-name

npm install gh-pages --save-dev

modify: json file

"homepage": "http://yourAccount.github.io/app-name"

"scripts": {  
//...  
"predeploy": "npm run build",  
"deploy": "gh-pages -d build"  
}

git init

git remote add origin https://github.com/yourAccount/app-name.git

npm run deploy

git add .  
git commit -m "First commit"  
git push -u origin HEAD

--update

git pull https://github.com/yourAccount/app-name.git

--reset pull origin sources

git remote set-url origin https://github.com/yourAccount/app-name.git

--choose one branch and clone

git clone -b master --single-branch https://github.com/yourAccount/app-name.git

--Temporarily save uncommitted changes before pulling. Stash does not resolve an existing merge conflict; resolve conflicts explicitly, and note that stash pop can also conflict.

git stash

git stash list

git stash pop "stash@{0}"

--Change branch

git branch  
git checkout newBranch

This is the historical Create React App + gh-pages workflow. Create React App is deprecated for new apps. Merge the JSON entries into the existing package.json; the `//...` line is explanatory and is not valid JSON. For Pages, select the gh-pages branch as the publishing source.
