# MRcoding 舊文遷移紀錄

處理日期：2026-10-23。來源為使用者指定的 `published/` 與 WordPress `uploads/` 備份。

- 匯入 196 篇已發布文章：2019 年 117 篇、2020 年 67 篇、2021 年 12 篇。
- 184 篇有文字／技術堪誤或必要的版本與時效補充；12 篇正文保留。
- 沿用既有 Astro frontmatter、文章版型、搜尋、標籤與分類頁。
- `pubDate` 保留原始資料庫的發表日期。來源未記載時區，因此使用日期欄位，不假造時區；原始完整日期時間保存在逐篇紀錄。
- `updatedDate` 為此次審校日。排序仍依 `pubDate`，舊文不會排到 2026 年新文之前。
- URL 使用 `mrcoding-原日期-WordPressID`，避免標題轉寫後撞名；同題不同解法保留各自身份。
- 分類收斂為 Engineering、Web Development、Blogging、Life；原站 AI 分類沿用。JavaScript/js、WordPress/WP 等標籤合併，C# 與 C++ 使用不同網址。
- 還原 201 個圖片檔：200 個 WebP 與 1 個原生 APNG。APNG 是格式教學的動態示範，保留原始 PNG 以確保格式與動畫符合內文；其餘圖片使用 WebP。
- 缺圖僅兩處：ID 32 的 AwardSpace 舊圖與 ID 1738 的第三方 WordPress 外掛示意圖，文章明示缺圖。
- 已轉換可識別的舊站文章互連。程式區塊內的舊站網址作為歷史範例保留。
- 舊版 API、過期活動、歷史價格與資源清單標明時效，不宣稱已在所有舊環境重現。

## 驗證

- 196 篇審校紀錄及摘要齊備，原始 ID 與日期可追溯。
- Astro 建置、Pagefind 搜尋索引與內部連結檢查。
- 代表性 Java/C# 範例編譯，DTW 與 TDEE 邊界案例。
- 100 個 JavaScript/JSX 程式區塊語法檢查，Reducer 與 Cookie 行為案例。
- 桌面與手機瀏覽器檢查文章圖片、主標題與水平溢出；結果另存驗證紀錄。

桌面錄影、Unity 場景、外部 CodeSandbox、真實裝置相容性與所有歷史服務未逐一執行整合測試。外部網站的 403、逾時或擋機器人回應不直接視為永久失效。
